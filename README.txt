MAIL INTERFACE — HTML AND CSS

Open index.html in a browser. Keep styles.css in the same folder.
No installation, external fonts, images, JavaScript, or internet connection is required.

index.html: Page content, semantic structure, and embedded SVG icons.
styles.css: Colors, three-column layout, typography, and responsive breakpoints.

This is a visual recreation of the supplied Mail.png screenshot. The toolbar,
folders, message rows, search field, and attachment are demonstration elements;
they do not send, search, modify, or download mail. The venue link reveals an
explanatory note using CSS. At smaller screen widths the layout adapts and the
message list scrolls horizontally on phones.

Customize the email content in index.html. Change the CSS variables at the top
of styles.css to adjust the theme. All sample email addresses use .example.
