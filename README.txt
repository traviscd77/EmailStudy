LINKED STUDENT INBOX

Setup
1. Extract this entire ZIP file. Keep the HTML files, mail.js, and styles.css together.
2. Copy your original assets folder alongside index.html. The uploaded files refer
   to assets/student-study.png and assets/student-pizza.png, which were not supplied.
3. Host the folder on your existing web server. For local testing with Python,
   run: python -m http.server 8000
   from this folder, then open http://localhost:8000/index.html in your browser.
   Use HTTP/HTTPS for reliable shared browser storage; file:// storage varies.
4. Configure your eye-tracking software with the hosted page addresses below.

Every message row is a real hyperlink and loads its own HTML page in the same tab.
You can also open these links directly. Previous and Next load those same pages.
The filenames are neutral so they do not reveal the correct classification.

Categorization
Keep, Delete, Report phishing, and Report junk remain available on every page.
Decisions persist in localStorage for the same browser profile and web origin.
Folder controls let participants review and revise their decisions.
Delete now leaves the selected email visible in Deleted Items so the page URL
continues to identify the email being viewed. Restore and Undo delete still work.
A direct link to a previously kept or deleted email opens that email in its folder.
Reporting retains the original behavior: reported messages also remain in Inbox.
Email-body links remain simulated and inactive, with destinations shown on hover.

Study sessions
The website does not send results to a server or collect gaze data. Your external
software records page visits and gaze. Browser storage is not a research database.
Use a fresh browser profile or clear this site's browser storage between participants.
The existing Reset reports button only clears reports; it does not clear Keep or
Deleted Items. Browser storage must be enabled to retain decisions between pages.
Use a separate browser profile for concurrent participants.

The original four regular, three junk, and three phishing emails are preserved.
